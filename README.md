# 🛡️ AI-Based Cyber Threat Detection & Alerting System

A cybersecurity platform designed to analyze network activity, identify potentially malicious behavior, generate automated alerts, and support threat response workflows.

---

## 🎯 Project Overview

Cybersecurity teams need to continuously monitor network activity to identify suspicious behavior and potential attacks.

This project provides a platform for analyzing network attack records and identifying potentially malicious activity through an automated detection and alerting workflow.

The system provides a web-based interface with separate frontend and backend components and supports containerized deployment.

---

## ✨ Key Features

- 🔍 Analyze network activity and attack records
- 🛡️ Detect potentially malicious activity
- 🚨 Generate automated security alerts
- 📊 Present detection information through a web interface
- 🧪 Support analysis using network log datasets
- 🐳 Containerized application deployment
- ⚙️ Jenkins-based CI/CD workflow
- 🔄 Separate frontend and backend architecture
